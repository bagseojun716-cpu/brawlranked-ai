# brawlranked-ai — 브롤 픽 AI

브롤스타즈 밴픽용 브롤러 추천 웹앱. 설치 필요 없음.

## 바로 실행

- **Windows**: `실행.bat` 더블클릭
- **Mac / Linux**: `./run.sh`
- 또는 `brawl-ai/index.html` 을 브라우저(크롬 추천)로 그냥 열기

## 사용법

1. 언어 선택 (오른쪽 위 🌍 버튼으로 다시 변경 가능)
2. 모드와 맵 선택
3. 브롤러 카드를 **우리팀/상대팀 칸으로 드래그** (모바일은 탭: 우리팀 3명 → 그다음 상대팀)
4. 픽된 브롤러를 클릭하면 제거
5. **추천** 버튼 → 맵 메타 + 상대 카운터 기준 추천 5명

브롤러 목록/이미지는 인터넷(Brawlify API)에서 받아오고, 연결이 안 되면 내장 목록(이미지 없이 이름)으로 동작합니다.
`http://localhost:3000/tier` 티어 서버는 선택 사항이며 localhost에서 열었을 때만 사용합니다.
