# 개인기 락커룸 (Skill Locker)

축구 개인기를 단계별로 정리해 올리고, 좋아요·조회수로 크리에이터 포인트를 쌓고, 연습할 기술을 내 락커에 모아 두는 공유 사이트입니다.

실제 사이트: https://claude.ai/artifact/VoSPHXCaaVwAfh5MBJycf3

## 주요 기능

- **기술 카드**: 실제 사용 사진 썸네일, 분류 색, 스타일(속임형·돌파형·쇼맨형·실전형), 난이도, 사용하는 발
- **상세 화면**: 위에서 본 발 동작 그림과 번호별 설명, 능력치, 따라하는 순서, 실전 팁, 실제 사용 사례와 영상 링크, 비슷한 개인기
- **개인기 올리기**: 썸네일 사진(자동 17:11 자르기), 필수/선택 항목 검사, 비슷한 개인기 직접 선택
- **크리에이터 포인트**: 다른 사람의 좋아요 1개 5점, 조회 1번 1점 → 루키·주전·에이스·레전드 등급과 노출 혜택
- **프로필**: 닉네임, 포지션, 주로 쓰는 발, 좋아하는 선수, 한 줄 소개
- **하단 탭**: 전체 · 내 락커 · 내가 올린 · 랭킹

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이지 전체 소스 (HTML·CSS·JS 한 파일) |
| `data/skills.json` | 기본 기술 8개 데이터 (단계, 사용 사례, 영상 링크, 능력치, 그림 템플릿, 사진 출처) |
| `images/` | 기본 기술 썸네일 8장 |
| `CREDITS.md` | 사진 저작자와 라이선스 |

## 실행에 대해

이 페이지는 claude.ai 아티팩트로 동작하도록 만들어졌습니다. 기술 목록, 좋아요, 조회수, 프로필, 썸네일은
아티팩트의 공유 저장소(`window.claude.use("db")`)에 저장되고, 로그인한 사용자 정보는 `window.claude.use("user")`로 가져옵니다.

그래서 `index.html`을 브라우저로 바로 열면 화면 틀은 보이지만 "저장소에 연결할 수 없어요"라는 안내가 나오고 기술 목록은 비어 있습니다.
다른 곳에서 독립 사이트로 운영하려면 이 두 부분을 Firebase 같은 백엔드로 바꿔야 합니다.
`data/skills.json`과 `images/`는 그때 초기 데이터로 쓸 수 있습니다.

저장소 구조:

| 컬렉션 | 문서 | 내용 |
|---|---|---|
| `skills` | 기술 id | 기술 정보 |
| `thumbs` | 기술 id | 썸네일 (`img`: JPEG data URL) |
| `likes` | 사용자 id | 그 사람이 좋아요한 기술 목록 (본인만 쓰기) |
| `views` | 사용자 id | 그 사람이 열어 본 기술 목록 (본인만 쓰기) |
| `profiles` | 사용자 id | 프로필 (본인만 쓰기) |
| `data/users/{id}/profile` | — | 내 락커에 담은 기술 (본인만 읽고 쓰기) |
